# Techno TLN WordPressi plokkteema

Õppeülesanne **„Wordpressi theme seadistamine uue Techno Figma kujunduse järgi”**.

Töö autor: **Ruslan Rebo**

## Tehtud

- WordPressi plokkteema on kohandatud Techno TLN Figma kujunduse järgi.
- Loodud on üks terviklik avaleht eestikeelse näidissisuga.
- Seadistatud on värvipalett, tüpograafia, paigutus ja nupud.
- Lisatud on päis, navigatsioon, hero-ala, statistikaplokk, õppesuundade kaardid, uudiste ala, CTA ja jalus.
- Kujundus kohandub ka kitsama ekraaniga.
- WordPressi **Edit Site → Styles** vaates on saadaval Typography, Colors, Background, Shadows, Layout ja Blocks.

## Failid

- `wp-content/themes/techno-tln/` – kohandatud WordPressi plokkteema lähtekood.
- WordPress Playgroundi täielik ZIP-koopia antakse õppekeskkonnas eraldi failina. Turvalisuse tõttu ei avaldata andmebaasi sisaldavat eksporti avalikus GitHubi repos.

## Teema paigaldamine

1. Laadi alla kaust `wp-content/themes/techno-tln`.
2. Paiguta see WordPressi kausta `wp-content/themes/`.
3. Aktiveeri teema WordPressis.
4. Ava **Edit Site**.
5. Globaalsed kujundusseaded asuvad **Edit Site → Styles**.
